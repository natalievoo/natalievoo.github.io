# natalievoo.github.io

My site, live at https://natalievoo.github.io. One page: a dock along the bottom, one panel on screen at a time.

- `index.html`: the page (the hero, the empty panels, the SVG filters)
- `style.css`: the look (tokens at the top: one ink, two greys, one accent)
- `script.js`: the name written stroke by stroke, the koi and ripples on the water canvas
- `assets/panels.js`: the dock and the panels (which one shows, the address bar)
- `assets/apps.js`: what each panel holds, built from `data/*.js`
- `assets/game.js`: chasing chickens
- `assets/site.js` + `assets/stickers.js`: the sticker tin and the peel
- `data/*.js`: all the content. Entries marked `sample: true` show a small tag until you replace them.

To preview locally, open `index.html` in a browser. To publish, commit and push to `main`; GitHub Pages updates in a minute or so.
