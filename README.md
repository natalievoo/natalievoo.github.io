# natalievoo.github.io

My studio, live at https://natalievoo.github.io. One room: press a seal along the bottom and a scroll unrolls with that part of the site in it.

- `index.html`: the room
- `style.css`: the look (colours at the top)
- `script.js`: the ink painting on the wall, the name written stroke by stroke, the koi
- `assets/studio.js`: the seals and the scrolls (open, drag, roll up, the address bar)
- `assets/apps.js`: what each scroll holds, built from `data/*.js`
- `assets/game.js`: chasing chickens
- `assets/site.js` + `assets/stickers.js`: the sticker tin
- `data/*.js`: all the content. Entries marked `sample: true` show a small tag until you replace them.

To preview locally, open `index.html` in a browser. To publish, commit and push to `main`; GitHub Pages updates in a minute or so.
